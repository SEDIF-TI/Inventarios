# Inventarios

Sistema de gestión de inventarios — Spring Boot + React + MUI.

## Estructura

```
Inventarios/
├── front-end/   # React + Vite + MUI (puerto 5173)
└── back-end/    # Spring Boot + Java 17 (puerto 8080)
```

## Levantar el proyecto

### Back-end
```bash
cd back-end
mvn spring-boot:run
```

### Front-end
```bash
cd front-end
npm install
npm run dev
```
